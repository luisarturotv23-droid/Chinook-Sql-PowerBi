# 🎵 Chinook — Análisis de datos con SQL y Power BI

## 📌 Descripción

Proyecto de business intelligence desarrollado utilizando la base de datos **Chinook**, con el objetivo de transformar información de ventas y música en un reporte interactivo en Power BI.

El proyecto combina **SQL para la extracción y estructuración de los datos** y **Power BI para el análisis y visualización de la información**.

## 🛠️ Herramientas utilizadas

* **SQL** — Creación de consultas y vistas para estructurar los datos.
* **Power BI** — Modelado, análisis y visualización.
* **DAX** — Creación de medidas para el análisis.
* **Power Query** — Preparación de los datos en Power BI.

## 🔄 Proceso

El desarrollo del proyecto se realizó siguiendo el siguiente flujo:

**Base de datos Chinook → SQL → Vistas → Power BI → Análisis y visualización**

### 1. SQL

Se crearon **dos vistas SQL** a partir de las tablas de la base de datos Chinook.

Las vistas permiten organizar y relacionar la información necesaria para posteriormente utilizarla en Power BI.

Las consultas utilizadas se encuentran en la carpeta SQL.

2. Power BI

Las vistas creadas en SQL fueron importadas a Power BI para realizar los dashboards.

En Power BI se realizó:

Preparación de los datos.
Modelado de la información.
Creación de medidas DAX.
Creación de visualizaciones.
Diseño del reporte interactivo.
📊 Dashboard

El reporte permite analizar diferentes aspectos relacionados con las ventas y la información musical de la base de datos Chinook.
